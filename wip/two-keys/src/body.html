How it works

  1. Write

    Nine drawers, from who to call first to your last words. Say where things are and how to reach them. Your draft is encrypted with a passphrase before it is kept on this device.

  2. Seal

    Choose your key holders and how many must come together. You get one sealed file and one key card per person. Then run the drill and watch the cards open it.

  3. Hand out

    Give each person their card and a copy of the file. The file is safe to email: without enough cards it is noise. Come back with your passphrase whenever something changes.

What to know before you rely on it

Nothing is sent anywhere
There is no account and no server behind this page. It works with your connection switched off. Your words leave this tab only inside the sealed file you save yourself.
One card is useless alone
A single card tells its holder nothing about what is inside. It takes the number of cards you chose, together with the file. Nobody reads it early.
It is not a will
It has no legal force and replaces neither a will nor a lawyer. It tells your people where things are and what you would like.
Nobody can rescue a lost file
There is no reset. If too many cards are lost and the passphrase is forgotten, the file stays shut for good. That is why the page asks you to run a drill.
How the file is made, for the technically minded

The sealed file is JSON. Your content is encrypted with AES-256-GCM under a random 256-bit key, with a fresh 12-byte nonce each time and the string two-keys-envelope/v1/<ID>/payload as additional data. That key is split with Shamir's secret sharing over GF(28) (reduction polynomial 0x11b), one point per card, the card number as x.

A card code is 45 bytes in Crockford base32: version, 4-byte envelope ID, cards needed, cards issued, card number, 32 key bytes, then the first 5 bytes of SHA-256 over two-keys-card-v1 followed by the first 40 bytes. The owner's passphrase (Unicode NFKC, trimmed, single spaces) is stretched with PBKDF2-HMAC-SHA-256, 600,000 iterations and a 16-byte salt, into a key that wraps the same 256-bit key with AES-GCM (additional data two-keys-envelope/v1/<ID>/owner-key).

That is everything needed to open a file without this page, today or in thirty years.

    What to do now

    1. Give each person their own card, on paper or in a message. One card each, never the full set in one place.
    2. Send everyone a copy of the sealed file and tell them what it is for.
    3. Keep your passphrase somewhere that is not with the file.
    4. Come back once a year, or after a big change, and seal again.
